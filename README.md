# Obscura

A premium photography booking application with separate dashboards for clients, photographers, and admins.

## Architecture
- Frontend: React + Vite + Framer Motion
- Backend: Node.js + Express
- Database: MongoDB

## Setup
1. Clone the repository
2. Run `npm install` in both `_frontend` and `backend` directories
3. Start the backend with `npm run dev` in `backend`
4. Start the frontend with `npm run dev` in `_frontend`
